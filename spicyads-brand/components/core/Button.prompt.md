Loud, confident call-to-action button — the spice-gradient `primary` is the default for hero/marketing CTAs.

```jsx
<Button variant="primary" size="lg" iconRight={<ArrowIcon/>}>Pide tu propuesta</Button>
```

Variants: `primary` (gradient + glow, the hero CTA), `solid` (flat ember red), `secondary` (paper with border), `ghost` (text-only), `dark` (near-black, for use on light spice fills). Sizes `sm | md | lg`. Use `full` to stretch, `as="a"` + `href` for links. Hover lifts 1px; press sinks. Keep label copy short, imperative, Spanish ("Empieza ya", "Habla con nosotros").
