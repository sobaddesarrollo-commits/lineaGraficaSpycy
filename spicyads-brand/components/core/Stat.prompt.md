Oversized metric in Anton with a mono label — the way SpicyAds shows results. Lead with the number.

```jsx
<Stat label="ROAS medio" value="6.4x" trend={{dir:'up', value:'+18%'}} sublabel="últimos 90 días" />
<Stat tone="spice" value="+312%" label="Leads" align="center" />
```

`tone="spice"` paints the numeral with the gradient. `trend.dir` `up`=green, `down`=alert-red.
