Surface container for grouped content. Warm paper + warm shadow by default — never a cold gray box.

```jsx
<Card variant="default" pad="lg" hover>
  <Eyebrow>SEO</Eyebrow>
  <h3>Posiciona tu marca</h3>
</Card>
```

Variants: `default` (paper), `flat` (sunken), `outline`, `dark` (near-black panel), `spice` (ember gradient fill — use sparingly for one hero stat/feature). `hover` lifts 3px. Radius is `--radius-lg`.
