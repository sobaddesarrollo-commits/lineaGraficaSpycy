Labeled text input. Focus ring is the spice ring; error turns the border alert-red.

```jsx
<Input label="Email" placeholder="hola@tuempresa.com" helper="Te respondemos en 24h" />
<Input label="Web" prefix="https://" error="Campo obligatorio" />
```

Supports `prefix` / `suffix` adornments, `helper`, `error`. Standard input attributes pass through.
